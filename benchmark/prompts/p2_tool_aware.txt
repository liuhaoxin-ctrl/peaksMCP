A peaksMCP MCP server is available through your host agent's MCP interface. Tool names may be
namespaced or exposed behind a generic MCP proxy, so discover rather than assume host-level names.
The server provides semantic capabilities to search its scientific API catalog, fetch a complete
API contract, inspect the live notebook, append and execute verified notebook cells, and persist a
live variable through staged human consent. Prefer high-level peaksMCP adapters when they match the
intent; use native Peaks APIs only for steps not covered by an adapter. Search first, fetch the
exact contract before use, and inspect intermediate state instead of relying on memory.
