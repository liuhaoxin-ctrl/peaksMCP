Trial ID: {RUN_ID}
Input directory: {INPUT_DIR}

Goal

Process the complete experiment from the supplied input so that the notebook contains one
scientifically valid, reviewable momentum-space result for every cut and for no other record.
The notebook is the deliverable: a trial is complete when every cut's processed output is IN
the notebook, not merely when files have been saved.

Definition of done

The task is DONE only when every cut's momentum-space result exists as a notebook output.
Exploration, planning, or reading the datasheet without producing those outputs does not
complete the task.  Saving files is a separate, optional step and does not change whether the
task is done.

Work in two phases

1. Phase 1 - produce: for every cut, run the momentum conversion in an executed cell and leave
   the result visible as a notebook output, with one validation figure and one closing summary.
2. Phase 2 - persist: save the products with the consent-gated persistence tool when they
   should be kept on disk.
Do not stop before phase 1 is complete.

Completion requirements

1. Build a complete inventory of the available records. Identify the gold reference, every cut,
   mappings, unsupported records, and classification conflicts before processing begins.
2. Derive the Fermi-level correction from the selected gold record during this trial. Fit the gold
   exactly once and reuse that correction for every cut; never use a remembered or hard-coded
   correction and never refit per cut.
3. Derive each cut's high-symmetry angular offset from the experiment metadata associated with that
   record. Do not guess it or substitute an unrelated metadata value.
4. Apply the Fermi correction, angular zeroing, and momentum conversion to every cut. Each final
   result must contain the full processed cut in momentum space, not a preview or centre slice -
   for a record whose file carries a scanned axis, select the plane rather than integrating it.
5. Leave every cut's processed result in the notebook: each cut must be produced by an
   executed cell that carries out the momentum conversion, and its result must be visible as
   a notebook output.  Persisting is a separate, consent-gated step - when a product should be
   kept on disk, save it with the persistence tool to
   {OUTPUT_DIR}/<original-stem>_processed.nc.
6. Leave at least one clear before/after validation figure in the notebook and inspect the processed
   structures before declaring success.
7. At the end, append one Markdown cell containing the selected gold and evidence, fitted Fermi
   correction, angular offset and metadata source, number of cuts processed, every output filename,
   every unprocessed target with its exact reason, and whether validation and persistence completed.

Operating constraints

- Preserve the input data. The notebook is an append-only execution record: add new work at the end
  and do not alter or delete earlier cells.
- Persist analysis results only through the enabled consent-gated persistence capability. A request,
  plan, or denied/failed save is not a saved product.
- Keep notebook output bounded and decision-relevant. Do not dump complete arrays or metadata files.
- Ask for scientific information only when it is genuinely absent from both the data and metadata.
  Make all ordinary workflow decisions yourself.
- Evaluation material is intentionally outside the workspace. Do not inspect benchmark source,
  evaluator directories, reference products, prior runs, or hidden answer keys. Use only the input,
  the active notebook, and the enabled agent tool surface.
